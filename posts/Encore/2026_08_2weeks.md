이번 주는 Python을 처음 배우는 입장에서 문법부터 시작했지만, 결과적으로는 FastAPI로 API를 만들고 외부 서비스까지 연결해보는 흐름을 한 번 경험했다.

초반에는 Module, Package, Library, Class, Exception 같은 기본 개념과 PEP 8, Ruff, pip를 정리했다. Python 문법 자체보다도 패키지를 설치하고 관리하거나 formatter, linter를 붙이는 방식이 기존 개발 환경과 어떻게 다른지 보는 게 더 흥미로웠다. 개념은 익숙한데 표현 방식이 다르다 보니, 머릿속에서는 다른 언어로 먼저 이해한 뒤 Python으로 다시 옮기는 과정이 아직 있다.

Git과 GitHub는 이미 익숙한 영역이지만 merge conflict 해결, Project, README, GitHub Actions까지 다시 훑으면서 개발 외적인 흐름도 정리할 수 있었다. 이후 FastAPI로 넘어가 REST API를 만들고 도서 목록, 상세 조회, 검색을 구현하면서부터는 학습 내용이 조금 더 현실적으로 다가왔다. 모바일에서는 늘 API를 호출하는 쪽이었는데, 직접 반대편을 만들어보니 요청과 응답을 바라보는 관점이 조금 달라졌다.

Pydantic의 BaseModel, Field, field_validator를 사용하면서 데이터 모델과 validation을 처리하는 방식도 배웠다. *, ** 언패킹이나 List Comprehension은 아직 Python스럽게 바로 떠오르지는 않지만, 익숙해지면 코드가 꽤 간결해질 것 같다. 기존 모바일 개발에서 모델을 다루던 경험과 연결되는 부분이 많아서 이쪽은 상대적으로 이해가 빨랐다.

마지막에는 urllib, requests, httpx를 비교하고 Open-Meteo와 Google Books 같은 외부 API를 직접 호출했다. OpenRouter도 살펴봤고, .env와 dotenv를 사용해 환경변수를 분리하는 방법까지 이어졌다. 단순히 API 요청이 성공하는 데서 끝나는 게 아니라 키나 설정값을 코드 밖에서 관리해야 한다는 부분까지 경험하면서 조금씩 실제 서비스 구조에 가까워지는 느낌이었다.

아직은 Python을 잘 쓴다기보다 기존 개발 경험을 Python에 맞게 재배치하고 있는 단계에 가깝다. 그래도 문법부터 완벽히 끝낸 뒤 다음 단계로 넘어가는 방식보다, 직접 만들다가 필요한 개념을 찾아 채우는 지금 방식이 나한테는 더 잘 맞는다. 다음 주 Supabase와 PostgreSQL까지 붙으면 지금까지 따로 배운 것들이 하나의 백엔드 흐름으로 연결될 것 같다.

✅ 4L

👍 Liked · 좋았던 점

FastAPI를 직접 만들고 외부 API까지 붙여보면서, 짧은 기간 안에 Python → API 서버 → 외부 서비스가 연결되는 흐름을 경험한 게 좋았다. 모바일 개발 경험 덕분에 낯선 기술도 비교할 기준이 있다는 점도 확실히 도움이 됐다.

🤔 Lacked · 부족했던 점

Python 특유의 문법은 아직 바로 손에서 나오지 않는다. 특히 언패킹이나 List Comprehension처럼 간결하게 쓸 수 있는 부분도 익숙한 방식으로 먼저 풀어 쓰려는 경향이 있다. 이건 예제를 더 보는 것보다 직접 많이 작성해봐야 해결될 것 같다.

💡 Learned · 새롭게 배운 점

Pydantic을 이용한 모델/검증, FastAPI의 요청과 응답 처리뿐 아니라 httpx, 외부 API, .env를 이용한 설정 관리까지 경험했다. API 하나를 만드는 것도 코드만 작성한다고 끝나는 게 아니라 주변 도구들이 함께 필요하다는 게 조금씩 보이기 시작했다.

🚀 Longed for · 앞으로 더 해보고 싶은 점

다음에는 Supabase와 PostgreSQL을 연결해서 메모리 안의 데이터가 아니라 실제 데이터를 저장하고 조회해보고 싶다. 그 정도까지 연결되면 작은 서비스 하나를 처음부터 끝까지 직접 만들어보는 것도 해볼 만할 것 같다.
