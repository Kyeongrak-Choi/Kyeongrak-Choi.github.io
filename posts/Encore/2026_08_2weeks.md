이번 주는 Python의 문법을 익히는 것보다 Python 생태계가 어떻게 구성되어 있고, 실제 서비스를 만들 때 어떤 식으로 연결되는지 감을 잡는 데 의미가 있었다.

Module, Package, Library, Class, Exception 같은 기본 개념부터 PEP 8, Ruff, pip까지 훑었다. 개념 자체는 모바일 개발을 하면서 이미 접했던 것들이라 어렵지는 않았지만, 같은 역할을 Python에서는 어떤 방식으로 풀어내는지 비교하면서 보는 게 훨씬 이해가 빨랐다. 특히 처음 접하는 언어일수록 문법 하나하나 외우는 것보다 패키지 관리나 개발 환경처럼 실제로 계속 사용하게 될 부분을 먼저 익히는 게 효율적이라는 생각이 들었다.

이후 Git/GitHub를 다시 정리하고 FastAPI로 넘어가면서 학습이 조금 더 재미있어졌다. REST API 개념을 기반으로 서버를 띄우고 도서 목록, 상세 조회, 검색 기능 등을 직접 만들어보니, 그동안 모바일에서 당연하게 호출하던 API의 반대편을 직접 구현해보는 느낌이었다. GitHub Actions까지 함께 살펴보면서 단순히 코드를 작성하는 것보다 개발부터 배포까지 이어지는 흐름도 다시 생각해볼 수 있었다.

Pydantic에서는 BaseModel, Field, field_validator를 다뤘고, *, ** 언패킹이나 List Comprehension처럼 Python에서 자주 사용하는 표현도 접했다. 처음에는 문법이 낯설었지만 모델 정의나 validation처럼 기존 개발 경험과 연결되는 부분은 생각보다 빠르게 이해됐다. 마지막에는 urllib, requests, httpx를 살펴보고 Open-Meteo API를 호출하면서, 이번 주에 배운 내용들이 조금씩 하나의 흐름으로 이어졌다.

아직 Python다운 코드를 자연스럽게 작성하는 단계는 아니다. 머릿속에서는 익숙한 언어로 먼저 구조를 만들고 Python으로 옮기는 과정이 한 번씩 들어간다. 그래도 처음부터 문법을 완벽하게 익히려고 하기보다는, 필요한 것을 만들면서 부족한 부분을 채우는 방식이 나한테는 더 잘 맞는 것 같다. 다음에는 Supabase와 PostgreSQL까지 연결해서 지금까지 배운 내용을 실제 데이터 흐름까지 확장해보고 싶다.

✅ 4L

Liked : 좋았던 점기초 문법에 오래 머무르지 않고 FastAPI와 외부 API 호출까지 빠르게 연결해본 점이 좋았다. 기존 모바일 개발 경험과 비교하면서 배우니 새로운 기술이라도 구조를 이해하는 속도는 확실히 빨랐다.

Lacked : 부족했던 점아직 Python 특유의 표현을 자연스럽게 사용하는 데는 익숙하지 않다. 개별 기능은 이해했지만 아무것도 없는 상태에서 프로젝트 구조를 처음부터 잡아보는 경험도 더 필요하다.

Learned : 새롭게 배운 점Python의 패키지 관리와 개발 도구부터 FastAPI, Pydantic, validation, HTTP 통신까지 기본적인 백엔드 흐름을 경험했다. 특히 기존에 클라이언트 입장에서 사용하던 API를 직접 구현해보면서 서버 쪽 구조를 조금 더 구체적으로 이해하게 됐다.

Longed for : 앞으로 더 해보고 싶은 점Supabase와 PostgreSQL을 연결해서 데이터를 저장하고 조회하는 단계까지 진행해보고 싶다. 이후에는 작은 서비스 하나를 처음부터 끝까지 만들어보면서 지금까지 배운 내용을 내 방식으로 다시 정리해보고 싶다.
