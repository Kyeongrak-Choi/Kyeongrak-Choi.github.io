## 1. 프로젝트 선정 배경

유튜브는 관심 있는 영상을 찾고 새로운 정보를 얻기에 편리하지만, 추천 알고리즘을 이용하다 보면 처음에 찾으려던 목적과 관계없는 쇼츠나 동영상을 계속 보게 되는 경우가 있다. 짧고 자극적인 콘텐츠가 연속해서 추천되면서 의도하지 않게 시청 시간이 늘어나거나, 정작 필요한 영상을 찾는 데 집중하기 어려워지기도 한다.

이러한 경험 때문에 기존에는 유튜브 추천 알고리즘을 꺼놓고, 구독한 채널에 새로 업로드된 영상을 직접 확인하거나 필요한 주제를 검색하는 방식으로 콘텐츠를 찾아보았다. 이 방법은 불필요한 추천을 줄일 수 있다는 장점이 있지만, 구독한 채널 밖에 있는 좋은 영상을 발견하기 어렵고 검색 결과도 조회수나 유튜브 내부 기준에 따라 정렬되기 때문에 사용자의 현재 목적에 정확히 맞는 영상을 고르는 데 한계가 있었다.

YouPick은 이러한 문제에서 출발한다. 사용자의 과거 시청 기록을 분석해 계속 영상을 노출하는 대신, 사용자가 지금 입력한 프롬프트와 조건만을 기준으로 후보 영상을 찾는다. 사용자가 원하는 주제와 난이도, 영상 유형을 직접 지정하면 그 조건에 적합한 영상을 선별하고, 왜 해당 영상을 추천했는지 함께 설명하는 것이 프로젝트의 핵심이다.

## 2. 문제 정의와 프로젝트 목적

기존 유튜브 이용 과정에서 발견한 문제는 다음과 같다.

- 추천 알고리즘을 통해 원하지 않는 쇼츠나 관련 없는 영상을 계속 보게 될 수 있다.
- 구독한 채널만 확인하면 새로운 채널이나 더 좋은 콘텐츠를 발견하기 어렵다.
- 일반 검색 결과만으로는 영상의 난이도와 설명 방식이 명확하지 않다.
- 조회수가 높은 영상이 사용자의 현재 목적에 가장 적합한 영상이라고 보기는 어렵다.
- 여러 영상을 직접 열어보고 비교해야 하므로 탐색에 시간이 많이 든다.

프로젝트의 목적은 유튜브 자체 알고리즘을 대체하는 대규모 추천 시스템을 만드는 것이 아니다. 사용자의 명시적인 요청을 이해하고, YouTube에서 후보 영상을 수집한 뒤, 해당 조건에 맞는 결과만 다시 정렬하여 보여주는 **의도 기반 영상 큐레이션 서비스**를 만드는 것이 목표다.

## 3. 서비스 개요

사용자는 다음 세 가지 값을 입력한다.

1. **주제:** 무엇에 관한 영상을 찾고 싶은지 입력한다.  
   예: `FastAPI와 Supabase를 이용한 로그인 구현`
2. **난이도:** 입문, 중급, 고급 중에서 선택한다.
3. **영상 유형:** 핵심 요약, 개념 설명, 실습·튜토리얼 중에서 선택한다.

서비스는 기본적으로 Shorts를 제외하도록 설정하고, 필요한 경우 사용자가 포함 여부를 선택할 수 있게 한다. 입력값을 받은 서버는 검색에 적합한 한국어·영어 키워드를 생성하고 YouTube Data API에서 후보 영상을 가져온다. 이후 제목, 설명, 태그, 영상 길이, 업로드 날짜, 조회수 등의 정보를 분석하여 사용자의 조건과 가까운 영상을 상위에 배치한다.

추천 결과에는 썸네일과 제목만 보여주는 것이 아니라 다음 정보를 함께 제공한다.

- 영상 제목, 채널명, 링크, 썸네일
- 영상 길이와 업로드 날짜
- 예상 난이도와 영상 유형
- 추천 점수
- 해당 영상을 추천한 이유

예를 들어 `FastAPI 인증 / 입문 / 실습`을 입력했다면, 결과에는 단순히 조회수가 높은 영상이 아니라 JWT 인증을 처음부터 구현하고 예제 코드를 제공하는 영상이 우선적으로 노출된다.

## 4. 핵심 기능과 MVP 범위

개발에 사용할 수 있는 시간이 실질적으로 이틀이므로, 완성도 높은 핵심 흐름을 만드는 데 집중한다.

### 4.1 필수 기능

- 주제, 난이도, 영상 유형 입력
- 입력 조건을 검색 키워드로 변환하거나 확장
- YouTube Data API를 이용한 후보 영상 검색
- 영상 제목, 설명, 태그, 길이, 조회수 등 상세정보 수집
- LLM을 이용한 난이도·영상 유형 분류 및 추천 이유 생성
- 간단한 가중치 기반 추천 점수 계산
- 상위 5개 영상 결과 제공
- Supabase에 영상 및 추천 결과 저장
- Redis를 이용한 동일 검색 결과 캐싱

### 4.2 시간이 남을 경우 추가할 기능

- 사용자의 `도움 됨 / 별로예요` 피드백 저장
- Shorts 포함 여부 또는 영상 길이 필터
- 추천 영상 저장 목록
- 검색 기록 조회

### 4.3 이번 프로젝트에서 제외할 기능

- 유튜브 계정 및 전체 시청 기록 연동
- 자체 머신러닝 추천 모델 학습
- 임의 영상의 자막 전문 수집 및 분석
- 복잡한 개인화 추천 대시보드
- 모바일 앱과 브라우저 확장 프로그램

## 5. 데이터 수집과 추천 방식

YouPick은 대규모 데이터셋을 먼저 구축하지 않고, 사용자가 검색할 때 필요한 후보 영상을 수집하는 방식으로 시작한다.

| 데이터 | 수집 방법 | 활용 목적 |
|---|---|---|
| 주제·난이도·영상 유형 | 사용자 입력 | 검색 및 추천 기준 |
| 영상 ID·제목·설명·채널 | YouTube 검색 API | 후보 영상 구성 |
| 태그·길이·조회수·업로드일 | YouTube 영상 API | 품질과 최신성 평가 |
| 난이도·유형·추천 이유 | LLM 분석 | 조건 일치 여부와 설명 제공 |
| 검색 및 추천 결과 | Supabase | 결과 재사용과 이력 관리 |
| 반복 검색 결과 | Redis | API 호출과 응답시간 절감 |

MVP에서는 다음과 같은 단순한 점수식을 사용한다.

```text
추천 점수 =
주제 관련도 40%
+ 난이도 일치도 20%
+ 영상 유형 일치도 15%
+ 영상 반응도 10%
+ 최신성 10%
+ 채널 신뢰도 5%
```

프로젝트 기간이 짧기 때문에 추천 모델을 별도로 학습하지 않는다. 제목과 설명의 키워드 일치도, LLM 분류 결과, 조회수와 업로드 날짜를 정규화한 값으로 점수를 계산한다. 추천 결과가 기대와 다를 경우 가중치를 빠르게 조정할 수 있도록 각 점수 항목은 독립적으로 구현한다.

## 6. 기술 구성

| 구분 | 기술 | 역할 |
|---|---|---|
| Frontend | 미정 | 조건 입력, 추천 결과 및 오류 표시 |
| Backend | FastAPI | API 제공, 검색·분류·추천 흐름 제어 |
| Database | Supabase PostgreSQL | 영상, 분석 결과, 검색 이력 저장 |
| Cache | Redis | 중복 검색과 외부 API 결과 캐싱 |
| External API | YouTube Data API v3 | 영상 검색 및 메타데이터 수집 |
| AI | LLM | 검색어 확장, 영상 분류, 추천 이유 생성 |

전체 처리 흐름은 다음과 같다.

```text
사용자 조건 입력
→ FastAPI 요청 검증
→ Redis 캐시 확인
→ YouTube API 후보 영상 수집
→ LLM 영상 분류 및 추천 이유 생성
→ 추천 점수 계산
→ Supabase 결과 저장
→ 상위 5개 영상 응답
```

## 9. 예상 위험과 대응 방안

- **YouTube API 호출 제한:** 검색 결과를 Redis와 Supabase에 저장하고 동일 요청의 반복 호출을 줄인다.
- **LLM 응답 지연:** 신규 영상만 분석하고 이미 분석한 영상은 DB 결과를 재사용한다.
- **추천 결과 품질 부족:** 복잡한 모델 대신 점수 항목을 분리하여 가중치를 빠르게 조정한다.
- **프론트엔드 미확정:** 첫날 오전까지 기술을 결정하고, 시간이 부족하면 단순 HTML·JavaScript 화면으로 구현한다.
- **짧은 개발 기간:** 로그인, 개인화, 대시보드보다 검색부터 추천 결과 출력까지의 핵심 흐름을 우선한다.
- **외부 API 장애:** 시연에 사용할 검색 조건과 결과를 미리 저장해 발표 당일 장애에 대비한다.

## 10. 기대 결과와 성공 기준

프로젝트가 성공했다고 판단하는 기준은 기능의 개수가 아니라 사용자가 입력한 조건에 맞는 영상이 실제로 추천되는지 여부다.

- 세 가지 입력값에 따라 추천 결과가 달라진다.
- 검색부터 상위 5개 영상 반환까지 전체 흐름이 정상적으로 동작한다.
- 각 추천 영상에 사용자가 이해할 수 있는 추천 이유가 표시된다.
- 동일 검색은 캐시를 통해 더 빠르게 응답한다.
- 발표 시 외부 API, LLM, FastAPI, Supabase, Redis가 연결된 과정을 설명할 수 있다.

YouPick은 유튜브를 더 오래 보게 만드는 서비스가 아니라, 사용자가 보고 싶은 것을 더 빠르게 찾도록 돕는 서비스다. 짧은 개발 기간에는 이 차별점을 명확하게 보여주는 하나의 완성된 추천 흐름을 구현하는 데 집중한다.
