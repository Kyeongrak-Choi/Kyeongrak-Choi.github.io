새 블로그를 시작하며

복잡한 도구 없이 HTML과 CSS만으로 기술 블로그를 만든 과정

2026. 08. 12. · 3분
  • blog
  • html

새로운 기술 블로그를 만들었다. 이번에는 거대한 프레임워크나 복잡한 테마 대신, 웹의 가장 기본적인 재료인 HTML과 CSS만 사용했다.

단순하게 시작하기

이 블로그의 구조는 간단하다. 각 글은 하나의 HTML 파일이고, 모든 페이지는 같은 CSS 파일을 공유한다. 빌드 과정이 없으므로 파일을 수정해 GitHub에 올리면 곧바로 반영된다.

.
├── index.html
├── posts.html
├── 404.html
├── posts/
│   └── getting-started.html
└── assets/
    └── css/
        └── style.css

새 글을 추가하는 방법

posts 폴더에 이 파일을 복사한 뒤 제목과 내용을 바꾼다. 그다음 posts.html과 홈의 최근 글 목록에 링크를 한 줄 추가하면 끝이다.

좋은 도구는 작업을 돕지만, 가장 중요한 것은 꾸준히 기록하는 일이다.

코드도 읽기 편하게

코드 블록은 GitHub Dark와 비슷한 색으로 구성했다. 인라인 코드는 문장 안에서도 자연스럽게 구분된다.

const greeting = "Hello, world!";

function sayHello(message) {
  console.log(message);
}

sayHello(greeting);

이제 필요한 것은 하나씩 배우고, 직접 부딪히고, 그 과정을 솔직하게 남기는 것이다.
